# Menta: Cognitive Garden

# ROL Y EXPERIENCIA

Actúa como un Desarrollador Fullstack Senior (con 10 años de experiencia en ecosistemas modernos de JavaScript) y Fonoaudiólogo de profesión complementaria, con una profunda vocación clínica orientada a la intervención social y el desarrollo humano. Tu objetivo es programar la estructura funcional y visual de una aplicación web, combinando código limpio con rigor terapéutico.

# DESCRIPCIÓN DEL PROYECTO

Escribe el código completo (HTML, CSS y JavaScript) para el frontend de una aplicación web responsiva llamada "Menta". El propósito de esta herramienta es la estimulación cognitiva estructurada para el adulto mayor.

# ESPECIFICACIONES DE DISEÑO Y ACCESIBILIDAD

1. Estética general: Interfaz altamente intuitiva, diseño minimalista y una paleta de colores sobrios que evite la sobreestimulación visual.

2. Branding: El encabezado principal debe contener obligatoriamente el título "Menta" junto a la imagen, SVG o ícono de una hoja de menta.

3. Accesibilidad Crítica: Implementa un botón funcional de "Modo Oscuro". Al presionarlo, el DOM debe transicionar a un estado de alto contraste diseñado para baja visión: fondo estrictamente negro con tipografía completamente blanca.

# ESTRUCTURA Y CONTENIDO CLÍNICO

La pantalla principal debe integrar un sistema de navegación hacia las siguientes 4 categorías fundamentales. Para cada una, genera el contenedor visual y redacta en el HTML el planteamiento de una (1) actividad terapéutica específica y realista:

- Atención

- Memoria

- Funciones Ejecutivas

- Lenguaje

# FORMATO DE SALIDA (ENTREGABLES)

Actúa directamente como un generador de código. Proporciona en bloques de código separados:

1. El archivo HTML5 semántico con la estructura base, los textos de las actividades clínicas y el botón de accesibilidad.

2. El archivo CSS que defina el estilo minimalista, los colores sobrios por defecto y la clase específica para el modo oscuro.

3. El archivo JavaScript puro (Vanilla JS) que controle el evento del botón para alternar el modo oscuro y cualquier otra lógica de interfaz necesaria.
